# edithngalame.github.io

My portfolio site: case studies of my ML and AI security projects.

- Live: https://edithngalame.github.io
- Pages are written as fragments in `src/` (head above the `<!-- /head -->` line, page below). `python build.py` wraps them into the HTML files GitHub Pages serves (`index.html`, `projects/*.html`).
- Shared styles and the message inspector live in `assets/`.
- No build tools or dependencies: plain HTML, CSS and JavaScript.
