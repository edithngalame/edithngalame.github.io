About

I came to machine learning from security, so I test my own work the way an attacker would. When a number looks too good, I go looking for the shortcut behind it.

In my first project that habit found two bugs in my own dataset: the validation split had no emails, and a model had memorised 25 harmless sentences. Fixing them made the scores lower and the results true.

I publish the datasets, models and notebooks behind every result, so anyone can check them.
